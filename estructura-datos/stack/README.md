# Clase Stack
## Definición
Es una estructura de datos que permite el almacenamiento de elementos del mismo tipo, donde la secuencia de almacenamiento se realiza por un único lugar llamado 'cima'

## Caracteristicas
- Maneja una estructura de tipo LIFO
- Las operaciones en la pila se realizan por la cima de la estructura 
- Para insertar un elemento dentro de la pila, se utiliza el método push()
- Para eliminar un elemento dentro de la pila, se utiliza el método pop()
- Para hacer busquedas y consultas dentro de la pila se usa el método peek()
- Para crear una pila con la clase stack se escribe: stack <tipo> nombre;
- Un capacidad de la pila es ilimitada.

## Métodos de la clase Stack
- push(); Agrega un elemento... pila.push()
- pop(); Retira y devuelve el elemento superior... pila.pop();
- peek(); Consulta un elemento superior sin retirarlo... pila.peek();
- empty(); Indica si la pila está vacia... pila.empty();
- search(); Busca un elemento desde la cima... pila.search();
- size(); Devuelve la cantidad de elementos... pila.size();

## Posibles return de los metodos
Si search() devuelve 0 lo encontró. Si devuelve -1 no lo encontró

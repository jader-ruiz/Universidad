# Priority Queue
## Definición
Es una clase de java que permite almacenar y administrar elementos de esta estructura con un criterio de prioridad
## Funcionamiento
    Ana     Juan    Pedro    Marcela    Gerardo
     3        1       5         2          4


        [Juan, Marcela, Ana, Gerardo, Pedro]
## Operaciones
- offer(): Inserte un elemento en la Cola (Estricto)
- add(): Inserte un elemento en la Cola
- peek(): Consulta un elemento de mayor prioridad
- poll(): Retira y devuelve el elemento de mayor prioridad (Estricto)
- remove(): Retira y devuelve el elemento de mayor prioridad
- size(): Devuelve la cantidad de elementos
- isEmpty(): Comprueba si la cola esta vacia
- clear(): Elimina todos los elementos
- contains(): Comprueba si existe un elemento
- iterator(): Permite recorrer los elementos
- toArray(): Convierte los elementos en un arreglo

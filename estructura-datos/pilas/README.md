# PILAS (STACKS)

## Definición
Es una estructura de datos ordenada de tal forma que solo se puede adicionar o eliminar datos por un extremo llamado cima.

## Características 
- Es una estructura de datos de tipo LIFO (Last In, First Out). Último en entrar, primero en salir
- La unica forma de acceder a los elementos es desde el tope de la pila
- Las operaciones de inserción y eliminación se realizan solamente en un extremo de la estructura
- La pila se puede implementar por medio de arreglos (pila estatica), o por medio de listas enlazadas (pila dinamica)

## Operaciones de una pila
### Crear pila
- Insertar (Push)
- Elimninar (Pop)
- Pila vacia (isEmpty)
- Pila llena
- Cima (Top)
- Fondo (Bottom)
- Tamaño 

### Crear pila vacia
- Adicionar un elemento en la pila
- Eliminar un elemento de la pila
- Comprobar que no tiene elementos
- Comprobar que la pila no tiene espacio
- Retorna el elemento sin eliminarlo
- El elemento que se encuentra al fondo
- Indica el número máximo de elementos

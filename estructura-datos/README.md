# 🧠 Estructura de Datos

Esta carpeta contiene los ejercicios y laboratorios correspondientes a la materia de Estructura de Datos. El enfoque principal es aprender a almacenar, organizar y manipular datos en memoria de manera eficiente utilizando **Java**.

## 🚀 Temas abordados

Los ejercicios están divididos en las siguientes categorías:

* **Arreglos Unidimensionales (`/arreglo_unidimensional`):** 
  * Recorridos, ordenamiento (creciente/decreciente).
  * Búsquedas y manipulación de posiciones (desplazamientos).
* **Matrices (`/matrices`):** 
  * Arreglos bidimensionales y operaciones matemáticas con ellos.
* **Manejo de Cadenas (`/cadenas` & `/ejercicios-cadenas`):** 
  * Uso de métodos de la clase `String` (`length`, `charAt`, `substring`, `equals`, `replace`, etc.).
  * Algoritmos de análisis de texto (contador de vocales, validación de palíndromos, contador de palabras).

## 📝 Cómo ejecutar
Cada carpeta de tema tiene su propia carpeta `src/` con el código fuente. Puedes compilar y ejecutar cualquier archivo `.java` individualmente desde tu terminal o IDE.

# Programación Intermedia

Este módulo recopila el desarrollo de la lógica fundamental y la introducción a la Programación Orientada a Objetos (POO) en Java.

## Contenido

El directorio está subdividido en tres secciones principales:

### 1. Repaso de Estructuras (`/repaso-estructuras`)
Programas para afianzar la sintaxis de Java y el uso de la consola.
* Uso de la clase Scanner para la lectura de datos (`LeerDatos.java`).
* Manejo de condicionales y ciclos integrados (`Condicional.java`, `Ciclos.java`).
* Implementaciones prácticas como una Calculadora y cálculo de áreas.

### 2. Práctica Básica en Java (`/practica-basica-java`)
Desarrollo del pensamiento computacional a través de las estructuras lógicas:
* **Estructura Secuencial:** Cálculos directos paso a paso (Nómina básica, Conversión de temperaturas, Área/Perímetro de figuras, Promedios ponderados y Tiempo de viaje).
* **Estructura Condicional:** Toma de decisiones mediante `if/else` y `switch` (Año bisiesto, Calculadora de IMC, Clasificación de triángulos, Sistema de calificaciones por letras y Tarifa de parqueadero).
* **Estructura Repetitiva:** Iteraciones y bucles (Juego de adivinar el número, Números primos en un rango, Suma de series matemáticas, Tablas de multiplicar extendidas y Validación de edades).
* **Arreglos y Matrices:** Algoritmos avanzados de almacenamiento (Inversión de arreglos, Búsqueda de nombres, Estadísticas de un grupo, Registro de ventas y la lógica del juego de Triqui).

### 3. Programación Orientada a Objetos (`/poo`)
Conceptos base del paradigma POO:
* Creación de clases, instanciación de objetos y encapsulamiento.
* Abstracción mediante clases como `NumeroNatural.java`, `Punto.java` y `Usuario.java`.

# Array Queue
## Definición
Es una clase en Java que permite almacenar y administrar elementos mediante una estructura de datos denomidada cola de doble extremo utiliza el concepto FIFO.
## Operaciones Principales
- addFirst() : Inserta un elemento al principio
- addLast() : Inserta un elemento al final
- offerFist() : Inserta al principio y devuelve true si tiene éxito
- offerLast() : Inserta al final y devuelve true si tiene éxito
- push() : Inserta un elemento al principio, como una pila
- getFirst() : Consulta el primer elemento
- getLast() : Consulta el ultimo elemento
- peek() : Consulta el primer elemento y puede devolver true
- peekFirst() : Consulta el primer elemento
- peekLast() : Consulta el ultimo elemento
- removeFirst() : Elimina el primer elemento
- removeLast() : Elimina el ultimo elemento
- pollFirst() : Elimina el primer elemento
- pollLast() : Elimina el último elemento
- pop() : Elimina el primer elemento, como una pila
- size() : Devuelve la cantidad de elementos
- clear() : Elimina todos lo datos
- isEmpty() : Comprobar si la cola esta vacía

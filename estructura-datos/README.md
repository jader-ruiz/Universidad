# Estructura de Datos

Este módulo contiene los ejercicios prácticos y algoritmos aplicados sobre las estructuras de datos fundamentales en Java.

## Contenido

El directorio está organizado por temas en los siguientes paquetes:

### 1. Arreglos (`/arreglos`)
Ejercicios sobre la declaración, inicialización y manipulación de vectores.
* Implementación de ordenamiento de forma creciente y decreciente.
* Lógica para el desplazamiento de números hacia adelante.

### 2. Cadenas (`/cadenas`)
Prácticas enfocadas en aprovechar los métodos de la clase `String`.
* **Métodos evaluados:** `charAt()`, `compareTo()`, `contains()`, `equals()`, `equalsIgnoreCase()`, `length()`, `replace()`, `substring()`, `toLowerCase()`, `toUpperCase()`.
* Algoritmo manual para invertir cadenas de texto.

### 3. Matrices (`/matrices`)
Implementación de arreglos bidimensionales, llenado y operaciones de recorrido clásico.

### 4. Ejercicios Aplicados (`/ejercicios`)
Problemas que integran y ponen a prueba los temas anteriores:
* **Arreglos:** Análisis de estaturas de estudiantes, generación de la Secuencia de Fibonacci y suma de vectores.
* **Cadenas:** Conteo de vocales, conteo de palabras en una oración y verificación de palíndromos.
* **Matrices:** Operaciones mediante métodos modulares.

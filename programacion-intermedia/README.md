# 💻 Programación Intermedia

En esta materia se consolidan los fundamentos de la lógica de programación y se introduce el paradigma de la Programación Orientada a Objetos (POO) utilizando **Java**.

## 🚀 Contenido de la materia

El código está organizado en diferentes módulos según el concepto evaluado:

### 1. Práctica Básica Java (`/practica-basica-java/src/`)
Contiene algoritmos fundamentales para desarrollar la lógica computacional:
* **Estructuras Secuenciales:** Operaciones matemáticas, cálculo de áreas, promedios y nóminas.
* **Estructuras Condicionales:** Validaciones lógicas, cálculo de IMC, año bisiesto y tarifas.
* **Estructuras Repetitivas (Ciclos):** Adivinanza de números, series matemáticas y rangos de números primos.
* **Minijuegos y Aplicaciones:** Incluye desarrollos prácticos integradores, como un juego de **Triqui** por consola y sistemas de registro de ventas.

### 2. Repaso de Estructuras (`/repaso-estructuras/src/`)
Ejercicios de refuerzo sobre los conceptos básicos (condicionales, ciclos, lectura de datos y métodos).

### 3. Programación Orientada a Objetos (`/POO/src/`)
Introducción al diseño de clases, encapsulamiento, instanciación y creación de objetos (ej. `Usuario`, `Punto`, `NumeroNatural`).

## ⚙️ Notas
Todos los scripts están diseñados para ejecutarse por consola, solicitando datos de entrada al usuario cuando es necesario y mostrando los resultados en la salida estándar.

# COLAS
## DEFINICION
Es una estrucutra de datos que consiste en que se inserte datos por un extremo y se eliminan datos por el extremo opuesto.
## CARACTERISTICAS
- Estructura de datos de tipo FIFO (First in, First out). 
- Un elemento se inserta en la parte final de la estructura
- Un elemento se elimina en la parte inicial de la estructura
- Una cola en java no tiene capacidad fija, sino que puede crecer o decrecer dinamicamente según sea necesario
- Hay varios tipos de cola:
    - Cola
    - Cola circular
    - Cola prioridad
    - Cola de doble extremo
- La cola se puede trabajar con arreglos o con listas enlazadas 
## OPERACIONES BASICAS
- Creación de la estructura
- Inserción de datos
- Eliminacion de datos
- Busqueda de un dato
- Ordenamiento
- Consultar un dato
- Actualizar un dato
